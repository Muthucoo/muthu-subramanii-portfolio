MUTHU SUBRAMANII PORTFOLIO — MOBILE ANIMATION FIX

This package contains only the updated index.html. It does not replace or delete your CV PDF.

HOW TO APPLY
1. Open https://github.com/Muthucoo/muthu-subramanii-portfolio
2. Confirm the branch is main.
3. Open the repository root (where index.html is listed).
4. Click Add file > Upload files.
5. Upload this package's index.html.
6. At the bottom, use commit message: Fix mobile orbit animation layout.
7. Choose Commit directly to main and click Commit changes.
8. Wait for GitHub Pages to finish deploying.
9. On your phone, open the portfolio and refresh. If an old version remains, close the tab and reopen the link, or clear the browser cache.

WHAT CHANGED
- Mobile orbit containers are now square and centred.
- All four orbit cards use compact, consistent mobile positioning.
- Conflicting top/bottom constraints are removed on mobile, preventing cards from stretching.
- Boardroom diagram is sized to the available screen width and its detail text has reserved space.
- Desktop styles and animation durations are not changed.
- Reduced-motion accessibility rules remain in place.

Keep the existing assets/Muthu_Subramanii_CV.pdf file. The homepage continues to link to that exact path.
