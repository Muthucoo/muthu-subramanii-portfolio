# Muthu Subramanii — Personal Portfolio

A responsive, single-page portfolio website built from the updated résumé supplied by Muthu Subramanii M.

## Package contents

- `index.html` — complete website. No build tools or external JavaScript libraries are required.
- `assets/Muthu_Subramanii_Resume.pdf` — downloadable résumé linked from the website.

## Preview locally

Open `index.html` in a modern browser. The site is responsive and can be opened directly from a local folder.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `muthu-subramanii-portfolio`.
2. Upload `index.html` to the repository root.
3. Upload the `assets` folder with `Muthu_Subramanii_Resume.pdf` inside it.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/(root)`, then save.
7. GitHub will publish the page at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Keep the relative path `assets/Muthu_Subramanii_Resume.pdf` unchanged unless you also update the résumé link in `index.html`.
